# ![Magi](/public/logo3d.webp)

A wizard worm that powers an orb.

![Wizard worm](/public/magi.webp)

Development uses TypeScript 7 for `bun run tsc` and the TypeScript 6 API
compatibility package for ESLint. The two npm aliases follow the
[TypeScript side-by-side setup](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/#running-side-by-side-with-typescript-6.0).
